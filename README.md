## 📌 About the Project
This is a responsive personal portfolio site showcasing my skills, featured project, education, and contact information. It's built with plain HTML, CSS, and JavaScript — no frameworks — with a code-editor-inspired design theme.

## ✨ Features
- Responsive layout that works across desktop, tablet, and mobile screens
- Animated "typing" effect in the hero section
- Smooth scrolling navigation
- Scroll-triggered reveal animations
- Sections for About, Skills, Featured Project, Education, and Contact

## 🛠️ Built With
- **HTML5** – page structure and content
- **CSS3** – styling, layout (Grid & Flexbox), and animations
- **JavaScript** – interactivity (typing effect, mobile nav, scroll reveal)
